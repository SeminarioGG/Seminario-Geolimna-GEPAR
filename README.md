# Seminario GeoLimna-GEPAR

Repositorio oficial del Seminario GeoLimna-GEPAR, dedicado a la publicación y divulgación de fascículos académicos sobre investigación interdisciplinaria en ingeniería, ambiente, automatización, robótica y visión artificial.

**ISSN digital:** 3115-2376

## Consulta y descarga de los volúmenes

Los fascículos se consultan y descargan exclusivamente desde los registros oficiales en **Zenodo**. Este repositorio GitHub alberga la página de presentación y no distribuye copias PDF de los volúmenes.

- **Volumen 1 — Investigaciones 2019–2022:** https://doi.org/10.5281/zenodo.19323630
- **Volumen 2 — Investigaciones 2023:** https://doi.org/10.5281/zenodo.19456152
- **Volumen 3 — Investigaciones 2024–2025:** https://doi.org/10.5281/zenodo.19864565

**Sitio web oficial:** https://seminariogg.github.io/Seminario-Geolimna-GEPAR/

Para citar un volumen, utiliza el DOI que aparece en su registro de Zenodo.
